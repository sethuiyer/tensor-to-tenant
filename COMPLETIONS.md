## Why this exists

The FAQ describes a fictional 1,008-day journey of a learner going
from `ls`/`cd` to deploying the OpenRouter-inspired gateway. That
story is illustrative, not a record. This file is the place for
real records.

The README's existing role list (Staff AI Engineer, AI
Infrastructure Engineer, etc.) describes the *target*. This file
will record *who got there*.

## What counts as a completion

Three tiers, one per stackable program:

| Tier | Weeks | Release |
|---|---|---|
| Foundations | 1–30 | Math, numerical routines, experimentation toolkit |
| Engineering + Systems | 31–69 | Tested primitives, system designs, MLOps tools, postmortem |
| LLM Platform | 70–108 | LLM/RAG work, inference benchmark, platform layer, capstone |

A completion entry is the learner's own write-up of what shipped,
what surprised them, and where the curriculum needed to be patched.
The entry should link to the learner's published portfolio
(release artifact: code, design docs, the gateway capstone if LLM
Platform).

The "Auror" tier — completing all 548 Leetcode Darbar problems on top
of one of the above — is documented separately in `09_interview/leetcode_darbar/`
when it happens. It is not a separate completion tier because the
Darbar is parallel to the curriculum, not part of it.
