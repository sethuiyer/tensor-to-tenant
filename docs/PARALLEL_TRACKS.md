## Operating rule

A parallel lane can deepen the current phase, but it cannot replace a core
deliverable or unblock a failed gate. The generated learner repo provides
`make forge=57`, `make design=54`, `make darbar=42`, `make agent=7.5`, and
`make auror` for the corresponding artifacts and optional badges.
